## Official Description
This course introduces the fundamental theory and numerical methods for computational mechanics. Topics include the weak formulation of boundary value problems, finite element method (FEM) fundamentals, shape functions and isoparametric elements, numerical integration, assembly procedures, and solving systems of linear equations. The course also covers advanced topics such as error estimation, adaptivity, and applications to structural mechanics, heat transfer, and fluid mechanics problems.

## 問題 1：5 個核心心智模型

### 1. 弱形式 (Weak Form) 與變分原理 (Variational Formulation)
**方程式 + 數字**：
- 強形式：∇·σ + f = 0 (平衡方程)
- 弱形式（虛功原理）：∫_Ω σ:ε(δu) dΩ = ∫_Ω f·δu dΩ + ∫_Γ σ_n·δu dΓ
- Ritz 法：泛函 J[u] = ∫_Ω (1/2)σ:ε - f·u dΩ 最小的解滿足弱形式
- Galerkin 法：∫_Ω (∇·σ + f)·v dΩ = 0，對所有 v ∈ V
- 學者：Ritz (1909), Galerkin (1915)
- 誤差估計：||u - u_h||_H¹ ≤ C·h^min(p,λ)（p = 多項式階數，λ = 正則性）

### 2. 有限元法 (FEM) — 剛度矩陣組裝
**方程式 + 數字**：
- 單元剛度矩陣：K_e = ∫_Ω B^T D B dΩ
- 全域剛度矩陣：K = ∪ K_e（稀疏、帶狀對稱）
- 自由度 n = 10⁴-10⁶（實際工程問題），求解時間 O(n²)-O(n³)
- 高斯積分：2×2 點（線性元）、3×3 點（二次元）
- 學者：Clough (1960) — 首次提出 FEM 這個名字
- 應用：結構分析、熱傳導、流體力學

### 3. 等參元 (Isoparametric Elements) 與數值積分
**方程式 + 數字**：
- Jacobian 矩陣：J = ∂x/∂ξ，det(J) > 0（映射有效性）
- 積分：∫_Ω f dΩ = ∫_{-1}¹ ∫_{-1}¹ f(ξ,η)·det(J) dξ dη
- 3×3 Gauss-Legendre 積分：精度 O(h⁶)（3 階多項式精確）
- 閉合應力：σ_closed = 1/V ∫ σ dV（平均應力）
- 學者：Irons (1966) — 等參元概念提出

### 4. 收斂性與誤差估計 (h-/p- 自適應)
**方程式 + 數字**：
- 能量範數誤差：||u - u_h||_E = √(σ:ε(u-u_h))
- 全域誤差估計：η = √(Σ_e η_e²)（殘差型估計器）
- h-自適應：細化網格（局部 h 減半，誤差 O(h²)）
- p-自適應：提高多項式階數（p: 1→3，精度提升 ~10×）
- Zienkiewicz-Zhu 後處理估計：σ*_h = Π σ_h（recovery operator）
- 學者：Zienkiewicz & Zhu (1987), Babuška & Rheinboldt (1978)

### 5. 非線性有限元 — 牛頓-拉夫森迭代
**方程式 + 數字**：
- 非線性方程：K(u)·u = F，非線性剛度 K(u) = ∂F_int/∂u
- 牛頓迭代：K_T(u_n)·Δu = F_ext - F_int(u_n)（切線剛度）
- 收斂準則：||R||/||F|| < 10⁻⁶（力殘差準則）
- 弧長法 (Arc-Length)：防止 snap-through instability
- 幾何非線性：大應變 Green-Lagrange 應變張量 E = 1/2(F^TF - I)
- 學者：Crisfield (1981) — 弧長法；Bathe (1996) — 增量非線性 FEM

## 問題 2：3 個根本分歧

### 分歧 A：位移法 vs. 應力元法 (Displacement vs. Mixed Formulation)
**位移法（主流）**：
- 優點：插值簡單、連續性要求低、COMSOL/ANSYS/ABAQUS 標準實現
- 缺點：應力奇異性（L 形角、裂縫尖端）
- 適用：線彈性、一般連續體
- 代表軟件：ANSYS Mechanical, ABAQUS Standard

**混合元法（Hu-Washizu）**：
- 優點：應力精度高、鎖定問題（shear locking、volumetric locking）天然避免
- 缺點：自由度多、穩定性條件（LBB stability）
- 適用：不可壓縮彈塑性、Reissner-Mindlin 板殼
- 代表學者：Reissner (1945), Mindlin (1951)
- 分歧核心：精度 vs. 計算效率

**引用**：Bathe, K.J. (1996). "Finite Element Procedures." Prentice Hall.

### 分歧 B：h-自適應 vs. p-自適應 vs. hp-FEM
**h-自適應**：
- 思想：細化網格（h → h/2）
- 收斂率：O(h^p)（p = 多項式階數）
- 實現：殘差估計器、Dörfler 標記
- 代表：Babuška, Zienkiewicz

**p-自適應**：
- 思想：提高階數（p → p+1）
- 收斂率：指數收斂（對於光滑解）
- 挑戰：振動模式、高階形函數計算
- 代表：Szabó (1986) — p-version FEM

**hp-FEM（最優）**：
- 思想：局部 h + 全局 p 組合
- 最優收斂率：O(exp(-α√N))（N 為自由度）
- 代表：Babuška & Guo
- 分歧核心：複雜度 vs. 精度極限

### 分歧 C：Explicit vs. Implicit 有限元
**Implicit（Newmark-β, θ-method）**：
- 優點：無條件穩定（θ ≥ 0.5）、大步長
- 缺點：每步需迭代求解（非線性）、矩陣分解 O(n³)
- 應用：結構準靜態分析、低速動力學

**Explicit（Central Difference）**：
- 優點：無需矩陣分解、簡單實現、天然並列
- 缺點：穩定性條件 Δt < Δt_cr = 2/ω_max（CFL 條件）
- 應用：撞擊、爆炸、高速動力學（LS-DYNA）
- 分歧核心：穩定性 vs. 效率

# 核心心智模型深化（中英對照）

## 1. 弱形式與變分原理 — 從強形式到 FEM 的橋樑

### 1.1 從強形式推導弱形式
**彈性力學邊值問題（強形式）**：
平衡方程：∇·σ + f = 0 in Ω
應變-位移：ε = 1/2(∇u + (∇u)ᵀ) in Ω
本構關係：σ = D:ε (胡克定律) in Ω
邊界條件：u = ū on Γ_D（位移邊界），σ·n = t̄ on Γ_N（應力邊界）

**推導弱形式**（乘以虛位移 v ∈ V，v|_Γ_D = 0 並積分）：
∫_Ω σ:ε(v) dΩ = ∫_Ω f·v dΩ + ∫_Γ_N t̄·v dΓ

這就是虛功原理（強形式的弱化形式）

### 1.2 Sobolev 空間框架
- V = {v ∈ H¹(Ω) : v|_Γ_D = 0}
- H¹(Ω) = {v : v ∈ L²(Ω), ∂v/∂x_i ∈ L²(Ω)}（一階弱導數存在）
- 能量範數：||v||_H¹ = √(||v||²_L² + ||∇v||²_L²)

### 1.3 Lax-Milgram 定理（弱形式解的存在唯一性）
若 a(u,v) 為 V-橢圓（ coercive）和連續（bounded），且連續線性泛函 F(v) 有界：
⇒ 弱形式存在唯一解

### 1.4 Ritz 法 vs. Galerkin 法
- Ritz：能量泛函最小化（僅當泛函存在時）
- Galerkin：弱形式正交性（更一般）
- 矩陣形式：K·a = F，K_ij = a(N_i, N_j)（對稱正定）

### 1.5 多尺度變分原理
- 古典：單一尺度 Ritz/Galerkin
- 多尺度：V⊗H¹, V_h ⊂ V（離散子空間）
- 誤差估計：||u - u_h||_E ≤ C·h^p（h = 網格尺寸，p = 階數）

## 2. 有限元剛度矩陣 — 從連續到離散

### 2.1 形函數構建原則
- 插值性：N_I(x_I) = δ_IJ（節點上的值）
- 單位分解：Σ_I N_I(x) = 1
- 連續性：P_k 連續性要求 C⁰ 形函數（Lagrange）或 C¹（Hermite）

### 2.2 線性三角形元（T3）
- 3 個節點（頂點），形函數：N_I = a_I + b_I x + c_I y
- 剛度矩陣：K_e = A_e/2 · B^T D B（A_e = 三角形面積）
- 精度：O(h²)（位移 O(h²)，應力 O(h)）

### 2.3 四節點雙線性四邊形元（Q4）
- 形函數：N_I = 1/4(1+ξ_I ξ)(1+η_I η)
- Jacobian 檢查：det(J) > 0（映射有效性）
- 問題：Shear locking（彎曲問題中 shear strain 被錯誤估計）

### 2.4 高階元（Serendipity, Lagrange）
- 二次元（P2, Q2）：精度 O(h³)
- 三次元（P3）：每邊 3 節點
- 計算代價：自由度增加，但誤差衰減更快

### 2.5 數值積分選擇
| 積分類型 | 線性元 | 二次元 |
|---------|--------|--------|
| 完全積分 | 2×2 Gauss | 3×3 Gauss |
| 減縮積分 | 1×1 Gauss（避免locking） | 2×2 Gauss |
| 過度積分 | — | 4×4 Gauss（穩定性） |

## 3. 求解大型線性方程組 — 直接法與迭代法

### 3.1 直接法
- Cholesky 分解：A = LL^T（對稱正定），O(n³/6)
- LU 分解：A = LU（一般情況），O(2n³/3)
- 稀疏矩陣技術：skyline storage、band storage、CSR format
- 實際問題：n = 10⁵-10⁶ 時，直接法內存需求 ~10-100 GB

### 3.2 迭代法
- 共軛梯度法 (CG)：對稱正定，收斂率 O(κ(A))^(1/2)
- GMRES：非對稱問題，restart 策略
- 多重網格法 (MG)：最優 O(n) 收斂性
- 前置條件：Jacobi、ICC(0)、ILU(k)

### 3.3 條件數估計
κ(A) = λ_max/λ_min（A 的條件數）
- 均勻網格：κ(A) ~ O(h⁻²)
- 網格細化後條件數惡化，預處理變得必要

### 3.4 并行計算
- 域分解 (FETI, Balancing Domain Decomposition)
- 自由度分割：每處理器 O(n/P)（P = 處理器數）
- 通信開銷：網格界面節點

### 3.5 動態時間積分
- Newmark-β 法：參數 β, γ 控制穩定性和精度
  u_{n+1} = u_n + Δt·v_n + Δt²/2[(1-2β)a_n + 2β a_{n+1}]
  v_{n+1} = v_n + Δt[(1-γ)a_n + γ a_{n+1}]
- 穩定性：γ ≥ 0.5, β ≥ γ/2（無條件穩定）

## 4. 誤差估計與自適應網格

### 4.1 後驗誤差估計器
- 殘差型：η_R = ||h·R||_L² + ||h^(1/2)·J||_L²（R = 內部殘差，J = 通量跳變）
- Recovery 型（ZZ estimator）：η_Θ = ||σ* - σ_h||_L²
- 估計效率：θ = η_est/η_true ≈ 0.8-1.2（目標範圍）

### 4.2 網格標記策略
- Dörfler 策略：選取最大貢獻的單元，累計達到 θ·Σ η_e
- 典型閾值：θ = 0.5-0.8

### 4.3 自適應循環
1. 初始化網格
2. 求解 FEM
3. 計算誤差估計
4. 標記需細化單元
5. 細化/粗化網格
6. 返回步 2（直到收斂）

### 4.4 收斂率比較
- 均勻細化：||u - u_h||_E = O(h^p)
- 自適應細化：||u - u_h||_E = O(N^(-p/d))（d = 維度）
- 指數收斂（hp-FEM）：||u - u_h||_E = O(exp(-α√N))

### 4.5 幾何奇異性處理
- 裂縫/裂紋：奇異元（crack tip element）或 XFEM
- L 形角落：自適應細化
- 邊界層：拉伸網格（stretching）或 ALE

## 5. 非線性計算力學 — 超越線性假設

### 5.1 材料非線性
- 彈塑性：屈服函數 f(σ, ε^p) = σ_eq - σ_y ≤ 0
- 流動法則：dε^p = λ·∂f/∂σ
- 應變硬化：σ_y = σ₀ + H·ε^p（線性硬化）
- 數值實現：Return Mapping Algorithm（徑向返回法）

### 5.2 幾何非線性
- Green-Lagrange 應變：E = 1/2(F^TF - I)
- 2nd Piola-Kirchhoff 應力：S = J·F⁻¹·σ·F⁻ᵀ
- 切線剛度：K_T = K_M + K_σ + K_L（大位移、大轉角）

### 5.3 接觸非線性
- 庫侖摩擦：|T_t| ≤ μ·T_n（接觸約束）
- 罰函數法：施加接觸條件，通過 penalty 參數 ε_p
- 拉格朗日乘數法：精確滿足約束，額外自由度

### 5.4 穩定性分析
- 分岔點檢測：det(K) ≈ 0（剛度矩陣奇異）
- 弧長法 (Arc-Length)：
  ψ(u, λ) = F_int(u) - λ·F_ext = 0
  l² = ||u - u_n||² + (λ - λ_n)²·β²
- Snap-through：弧長法成功追蹤的關鍵

### 5.5 連續介質力學框架
- 速率型方程：σ̇ = D:(ε̇ - ε̇^p)（Jaumann 導數）
- Updated Lagrangian vs. Total Lagrangian（UL vs. TL）
- 變形梯度：F = I + ∂u/∂X（材料描述）

## 深度自測問題詳解

**Q1**: 推導 1D 桿件的單元剛度矩陣（長度 L，EA 為常數，線性形函數）。
**解答**：B = [dN₁/dx, dN₂/dx] = [-1/L, 1/L]；K_e = ∫₀ᴸ B^T EA B dx = EA/L · [1 -1; -1 1]

**Q2**: 什麼情況下會發生 shear locking？如何用 reduced integration 緩解？
**解答**：當彎曲變形主導時，Q4 元的 shear strain 被約束為零（約束滲透）。Reduced integration（1×1 Gauss）使 shear energy 為零，緩解但可能導致 spurious zero-energy mode（沙漏模式）。Hourglass control 可抑制。

**Q3**: 證明 CG 方法對稱正定矩陣 A 的收斂率為 O(κ(A)^(-1/2))。
**解答**：||e_k||_A ≤ (1-2/(κ+1))^(k/2) ||e₀||_A；其中 κ = λ_max/λ_min；這是 Chebyshev 多項式推導的結果

**Q4**: 在 Newmark-β 方法中，取 γ = 1/2, β = 1/4（平均加速度法）。證明其無條件穩定。
**解答**：Newmark-β 的穩定性條件要求：γ ≥ 1/2 且 β ≥ γ/2。當 γ = 1/2, β = 1/4，條件滿足，因此無條件穩定（energy-conserving）

**Q5**: 什麼是 LBB 穩定性條件？給出一個不穩定的混合元例子。
**解答**：LBB 條件：inf sup_{(σ,u)} (σ, ε(u)) / ||σ||_div / ||u||_H¹ > 0；不穩定例子：Q1-P0 元（位移線性，壓力常數）對不可壓縮問題，會出現 pressure checkerboarding

**Q6**: 使用 Zienkiewicz-Zhu Recovery 方法計算應力精度改善。
**解答**：σ* = Σ N_I(x) · (1/|ω_I| ∫_Ω N_I σ_h dΩ)（對每個節點週圍補片平均）；||σ* - σ_h|| 通常比 ||σ - σ_h|| 小 2-3 倍

**Q7**: 解釋為什麼離散裂縫模型（Fictitious Crack Model）比 Griffith 理論更容易數值實現。
**解答**：Griffith 理論要求連續跟蹤裂縫尖端（奇異場）；Fictitious Crack Model 離散化裂縫（ cohesive zone），用 traction-separation law，數值穩定，不需要奇異元

**Q8**: 什麼是 hourglass mode？如何檢測和抑制？
**解答**：Hourglass mode 是 reduced integration 导致的零能量變形模式。檢測：內力在 hourglass 模式下為零但幾何變形存在。抑制：hourglass stiffness（人工剪切剛度）或 hourglass control parameter

**Q9**: 推導 Rayleigh-Ritz 法和有限元的誤差估計式。
**解答**：Céa 引理：||u - u_h||_V ≤ C/α · inf_{v_h ∈ V_h} ||u - v_h||_V；對於 FEM，inf ||u - v_h|| ≈ h^p · |u|_p+1；故 ||u - u_h||_H¹ ≤ C · h^p · |u|_p+1

**Q10**: 什麼是固有應變法（Eigenstrain）？如何在熱應力分析中使用？
**解答**：固有應變 ε* 為無應力狀態下的自發應變（如熱膨脹 ε_th = α·ΔT）。總應變 ε = ε_el + ε*；σ = D:(ε - ε*)；在弱形式中作為初應變項處理

```mermaid
    D --> E{||R|| < Tol?}

```
