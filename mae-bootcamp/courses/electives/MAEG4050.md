# MAEG4050 Modern Control Systems Analysis and Design

**CUHK MAE | Major Elective | 3 units**
**Stream**: Robotics and Automation / Mechatronics

---

## Official Description

This course is designed to equip students with the knowledge of modern control systems analysis and design, and skills of control theory for practical applications of industrial automation systems. It will cover the following topics: state space representation, realizability, stability, controllability, observability; linear control design methods including pole placement, observer, asymptotic tracking and disturbance rejection, internal model design, and feedforward design; introduction to nonlinear systems. Various examples, e.g., robot control, satellite's attitude control and servomechanism are included.

**Learning Outcomes**: (1) Master state space analysis; (2) Design pole placement controllers; (3) Apply observer design; (4) Handle nonlinear systems.

**Textbook**: K. Ogata, *Modern Control Engineering*, 5th Edition, Prentice Hall.

## 問題 1：5 個核心心智模型

### 1.1 狀態空間分析 — 內部視角

**方程式 / 核心原理**：
$$\dot{\mathbf{x}} = \mathbf{A}\mathbf{x} + \mathbf{B}\mathbf{u} \quad \mathbf{y} = \mathbf{C}\mathbf{x} + \mathbf{D}\mathbf{u}$$
$$\mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}(0) + \int_0^t e^{\mathbf{A}(t-\tau)}\mathbf{B}\mathbf{u}(\tau)d\tau$$

**穩定性**：$\mathbf{A}$ 的所有特徵值滿足 $\text{Re}(\lambda_i) < 0$。

**可控性**：$\text{rank}[\mathbf{B}\ \mathbf{A}\mathbf{B}\ \cdots\ \mathbf{A}^{n-1}\mathbf{B}] = n$。

---

### 1.2 極點配置 — 期望閉環動力學的工程設計

**方程式 / 核心原理**：
$$\det(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K}) = \alpha_c(s) \quad \text{（閉環特徵多項式）}$$
$$\alpha_c(s) = (s - p_1)(s - p_2)\cdots(s - p_n) \quad \text{（期望特徵多項式）}$$

**選擇期望極點**：
- 二階近似：$\zeta = 0.7$，$\omega_n = 4/T_s$（2% 調整時間 $T_s$）
- 避免極點過於左側（過度控制能量）

---

### 1.3 觀測器設計 — 狀態估計的數學基礎

**方程式 / 核心原理**：
$$\dot{\hat{\mathbf{x}}} = (\mathbf{A} - \mathbf{L}\mathbf{C})\hat{\mathbf{x}} + \mathbf{B}\mathbf{u} + \mathbf{L}\mathbf{y}$$
$$\mathbf{L} = \mathbf{Y}\mathbf{O}^{-1} \quad \text{（龍伯格公式）}$$

**分離原理**：控制器和觀測器的極點可獨立設計，閉環穩定性由控制極點和觀測器極點共同決定（需滿足足夠快的觀測器）。

---

### 1.4 伺服控制與擾動抑制 — 零穩態誤差

**方程式 / 核心原理**：
$$\mathbf{u} = -\mathbf{K}\mathbf{x} + \mathbf{K}_I\int_0^t \mathbf{e}(\tau)d\tau \quad \mathbf{e} = \mathbf{r} - \mathbf{y}$$

**內模原理 (Internal Model Principle)**：
$$\mathbf{W}(s) = \frac{1}{s^p} \quad \text{（對階躍輸入 }p=1\text{）}$$

若干擾/參考信號是某類型的動力系統的輸出，則包含該動力系統模型於反饋環路可實現漸進干擾抑制和零誤差跟踪。

---

### 1.5 非線性系統簡介 — 線性化與局部穩定性

**方程式 / 核心原理**：
$$\dot{\mathbf{x}} = f(\mathbf{x}, \mathbf{u}) \approx f(\mathbf{x}_e, \mathbf{u}_e) + \left.\frac{\partial f}{\partial \mathbf{x}}\right|_{eq}(\mathbf{x} - \mathbf{x}_e) + \left.\frac{\partial f}{\partial \mathbf{u}}\right|_{eq}(\mathbf{u} - \mathbf{u}_e)$$

**雅可比線性化**：
$$\delta\dot{\mathbf{x}} = \mathbf{A}_j\delta\mathbf{x} + \mathbf{B}_j\delta\mathbf{u} \quad \mathbf{A}_j = \left.\frac{\partial f}{\partial \mathbf{x}}\right|_{eq}$$

## 問題 2：3 個根本分歧

### A/B 分歧 1：狀態反饋 vs. 輸出反饋

**A 方（狀態反饋）**：全部狀態可用，需要全狀態觀測器或直接測量。性能最優（可達可控範圍內任意極點）。

**B 方（輸出反饋）**：僅用輸出 $\mathbf{y}$，無法實現任意極點配置。對單輸出系統，需使用觀測器。

---

### A/B 分歧 2：LQR vs. 極點配置

**A 方（極點配置）**：直接指定極點，瞬態行為明確。缺點：對噪聲和建模誤差不敏感。

**B 方（LQR）**：自動平衡性能和控制能量。缺點：閉環極點位置由代價權重決定，不直觀。

---

## 問題 3：10 個深度問題

1. 給定一個三階系統，用可控性矩陣方法檢驗可控性，並用 Ackermann 公式設計狀態反饋。

2. 設計一個二階伺服機構的觀測器，將估計極點放在 $s = -20$。

3. 比較反饋補償器和串聯補償器（反饋 vs. 前饋）在 MIMO 系統中的應用。

4. 推導干擾抑制的內模原理，說明如何選擇內部模型 $1/s$ 或 $1/(s^2+a_1s+a_0)$。

5. 分析非線性擺系統的雅可比線性化，確定局部穩定區域。

6. 設計一個狀態估計器用於移動機器人的位置和速度估計。

7. 說明實現性（realizability）的概念：什麼條件下存在一個最小階實現？

8. 用 MATLAB/Simulink 模擬一個 DC 馬達速度控制的狀態空間控制器。

9. 比較連續時間和離散時間 LQR 的離散 Riccati 代數方程差異。

10. 設計一個雙閉環（內環速度控制 + 外環位置控制）的級聯控制架構，確定各環的帶寬關係。
