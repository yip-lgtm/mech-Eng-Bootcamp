## Course Format Standard

Every course file follows the research-based format:

```
5MM  — 5 Core Mental Models (方程式 + 數字 + 學者)
3DG  — 3 Fundamental Disagreements (A/B 方 + 引用)
10Q  — 10 Probing Questions (深度理解題)
5DD  — 5 Deep Dives (中英對照 + 關鍵方程式)
10SL — 10 Self-Test Solutions (完整解題過程)
5MR  — 5 Mermaid Diagrams (時間線 + 流程圖)
```

⚠️ Some elective files (marked 43 lines) are stubs — see full content in overlapping course files.
