# ENGG2720 Complex Variables for Engineers

**Phase 1 | Priority: ★★**  
**Why critical**: Tools for control theory, fluid dynamics, electromagnetics and signal processing.

---

## 1. 5 Core Mental Models Every Expert Shares

1. **Analytic Functions are Extremely Rigid** — Satisfying Cauchy–Riemann has strong consequences.
2. **Contour Integrals and Residues** — Powerful evaluation technique for real integrals.
3. **Conformal Mapping Preserves Angles** — Useful for potential flow and electrostatics.
4. **Laurent Series Generalises Taylor** — Essential for classifying singularities.
5. **Complex Representation of Sinusoids** — Phasors are complex numbers in disguise.

---

## 2. 3 Places Experts Fundamentally Disagree

### Disagreement 1: Theory-Heavy vs Application-Driven Presentation
- Theory reveals beauty and power. Applications keep engineers motivated.

### Disagreement 2: How Much Topology / Rigorous Analysis
- Some topology clarifies. Heavy analysis belongs in pure mathematics courses.

### Disagreement 3: Link to Control Theory Early or Late
- Early motivates the subject. Late requires more maturity in systems.
