## 1. 5 Core Mental Models Every Expert Shares

1. **Kirchhoff’s Laws are Conservation Statements** — KCL is charge conservation; KVL is energy conservation.
2. **Linearity Enables Superposition** — Most analysis techniques rest on linearity.
3. **Thevenin / Norton Equivalents Reduce Complexity** — Any linear network looks like a source + impedance from two terminals.
4. **Frequency Domain Reveals Steady-State Sinusoidal Behaviour** — Phasors turn DEs into algebra.
5. **Transients are Solutions of Differential Equations** — Natural + forced response; time constants set speed.

---

## 2. 3 Places Experts Fundamentally Disagree

### Disagreement 1: Time-Domain vs Frequency-Domain First
- Time-domain is fundamental. Frequency-domain is daily practice for AC and filtering.

### Disagreement 2: How Early to Introduce Op-Amps
- Early: ubiquitous in sensors and control. Later: passive intuition first.

### Disagreement 3: Simulation vs Hand Analysis
- Simulation handles complexity. Hand analysis builds insight and debugging skill.
