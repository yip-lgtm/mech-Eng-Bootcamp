## 📂 課程格式

所有 course files 採用 **袁騰飛格式** (5MM/3DG/10Q/5DD/10SL/5MR):

| Element | 內容 |
|---|---|
| **5MM** | 5 個核心心智模型 (方程式 + 數字 + 學者) |
| **3DG** | 3 個根本分歧 (A/B 方 + 引用) |
| **10Q** | 10 個深度問題 |
| **5DD** | 5 個深度 dive (中英對照) |
| **10SL** | 10 個 solution |
| **5MR** | 5 個 Mermaid 圖 |
